# Структура проекта

[English](STRUCTURE.md) · **Русский**

Как устроен open-uniwill-cc: что где работает, за что отвечает каждый файл и с чего начать, если нужно что-то
изменить. Сборка и отладка: [BUILD.md](BUILD.md#сборка-и-отладка). Подробно о возможностях: [FEATURES.md](FEATURES.md).
Протокол EC: [PROTOCOL.md](PROTOCOL.md).

## Как это работает

```text
            ┌──────────── сеанс пользователя ──────────────┐
            │  окно (веб-интерфейс)  трей / агент сеанса   │
            │  bin/uwcc              ControlCenter.exe     │
            │  uwccd/web/*           bin/uwcc-agent        │
            └──────────┬───────────────────┬───────────────┘
                       │ HTTP + SSE, 127.0.0.1, токен
            ┌──────────▼───────────────────▼───────────────┐
            │  служба uwccd (root / LocalSystem)           │
            │  api → service → fan / settings / lighting   │
            │        monitor / automation / watercooler    │
            └──────────┬───────────────────┬───────────────┘
                       │ EC RAM, ACPI      │ USB HID, Bluetooth LE
   Linux: kernel/uwcc.ko (/dev/uwcc)       клавиатура ITE 829x,
          или acpi_call                    СЖО
   Windows: UWACPIDriver.sys (драйвер OEM)
```

- **Одна служба на две системы.** `uwccd` — один и тот же код на Python для Linux и Windows; различаются только
  низкоуровневые части (`uwccd/ec.py` на Linux, `uwccd/win/` на Windows).
- **Железом управляет служба.** Она работает с правами администратора, применяет настройки при запуске и после сна,
  ведёт кривые вентиляторов и СЖО без открытого окна.
- **Всё остальное — клиенты** её локального HTTP API: окно, трей / агент сеанса и `uwccctl`. API слушает только
  `127.0.0.1`, для изменений нужен токен ([SECURITY.md](../SECURITY.md)).
- **Настройки** хранятся в `/var/lib/uwcc` (Linux) или `C:\ProgramData\UWCC\data` (Windows); токен — в
  `/run/uwcc/token` или `C:\ProgramData\UWCC\run\token`.

## Верхний уровень

| Путь | Что |
|---|---|
| `uwccd/` | служба и веб-интерфейс |
| `uwccd/win/` | части для Windows, приложение в трее, хост службы |
| `uwccd/lighting/` | подсветка клавиатуры; `oem/` — код на основе программы производителя (проприетарный) |
| `uwccd/clevo/` | **Control Center 3.0 / Clevo** — отдельный экспериментальный модуль: транспорт DCHU (`transport.py`: драйвер Control Center 3 на Windows, `/dev/uwcc` на Linux, симуляция) и функции (`manager.py`) — [CLEVO.ru.md](CLEVO.ru.md) |
| `uwccd/web/` | интерфейс: `index.html`, `app.js`, `app.css`, `i18n.js` (русские строки), значки |
| `bin/` | `uwcc` (окно), `uwcc-agent` (агент сеанса Linux), `uwccctl` (командная строка) |
| `docs/CLI.ru.md` | справочник командной строки (`docs/CLI.md` — английский) |
| `docs/EC/` | регистры EC, OEM-драйвер и WMI, настройки WMI, `ec_tool.py` |
| `man/` | справочная страница `uwccctl.1` (английская; `man/ru/` — русская), ставится `install.sh` |
| `kernel/` | модуль ядра Linux `uwcc` — доступ к EC и горячие клавиши (GPL-2.0, DKMS) |
| `packaging/` | Linux: юнит systemd, хук сна, ярлыки, правило polkit |
| `windows/` | спецификация PyInstaller и точки входа, скрипт Inno Setup, `install.ps1` / `uninstall.ps1` |
| `proprietary/` | ACPI-драйвер производителя и заводские таблицы вентиляторов (не входят в код MIT, необязательны) |
| `tests/` | тесты на симуляции EC (`python3 -m unittest discover -s tests`) |
| `tools/re/` | инструменты для изучения оригинальной программы (дамп и разбор .NET IL) |
| `docs/` | документация и скриншоты |
| `install.sh`, `uninstall.sh` | установка и удаление на Linux |
| `build.cmd`, `build_windows.ps1` | сборка для Windows |

## Служба — `uwccd/`

**Ядро**

| Файл | Что |
|---|---|
| `__main__.py` | параметры запуска службы (`--mock`, `--backend`, `--port`, `-v`) |
| `__init__.py` | версия, контакты, штамп сборки |
| `service.py` | ядро: определяет платформу, запускает все части и потоки, собирает состояние для интерфейса, события |
| `api.py` | локальный HTTP API, файлы интерфейса, поток событий (SSE) для окна и трея |
| `store.py` | JSON-файлы настроек (атомарная запись) |
| `settings.py` | переключатели (клавиша Win, Fn lock, тачпад, питание USB, камера, MUX…) и защита батареи |

**Доступ к железу**

| Файл | Что |
|---|---|
| `ec.py` | доступ к EC: модуль ядра, `acpi_call`, симуляция (`--mock`), заглушка «нет доступа», кэш чтения для медленных путей |
| `ecaccess.py` | выбор доступа к EC в Windows (OEM-драйвер / WMI бета), предупреждение WMI, `ec_wmi.json` |
| `drivercheck.py` | проверка пакета OEM-драйвера перед установкой; копирование из хранилища драйверов Windows |
| `admin.py` | ключ администратора и разблокировка настроек менеджера EC на 10 минут |
| `busy.py` | долгие операции, которых ждёт окно («Применяю…», кривая вентиляторов в фоне) |
| `platformdb.py` | профили платформ (`platforms/*.json`), жёсткие потолки, проверка |
| `selfcheck.py` | самопроверка EC: ступень 1 — чтение, ступень 2 — запись с проверкой и восстановлением, черновик профиля |
| `platforms/` | встроенные профили платформ (`uniwill-0x10.json`, `generic-uniwill.json`) |
| `regs.py` | карта регистров EC, которые использует оригинальная служба |
| `hw.py` | определение платформы: номер проекта, возможности, названия моделей, уровень поддержки |
| `nvram.py` | переменная UEFI `UniWillVariable` (настройки, которые хранит прошивка) |
| `events.py` | горячие клавиши (WMI / модуль / опрос EC), таймер бездействия, привязка приложений к режимам |

**Режимы, вентиляторы, питание**

| Файл | Что |
|---|---|
| `fan.py` | режимы, профили и таблицы вентиляторов (коммерческие проекты), хранение таблиц |
| `fan_std.py` | режимы Office / Gaming / Turbo / Custom остальных проектов, лимиты PL1 / PL2 / PL4, cTGP |
| `gputemp.py` | целевая температура GPU NVIDIA |
| `nvpowerd.py` | проверка службы NVIDIA, которая отвечает за Dynamic Boost |
| `hwoc.py` | «суперпроизводительность» с СЖО (таблица EC + уровень разгона в прошивке) |

**Подсветка, СЖО, мониторинг, дополнительно**

| Файл | Что |
|---|---|
| `lighting/keyboard.py` | управление подсветкой клавиатуры (ITE RGB или одноцветная через EC) |
| `lighting/ite.py` | контроллер ITE 829x с RGB на каждую клавишу через USB HID |
| `lighting/fx.py` | эффекты BetterRGB, которые рисует служба: кадры, переходы, калибровка белого, полоса в верхнем ряду, темп кадров (из BetterRGB, MIT) |
| `lighting/oem/` | аппаратные и программные эффекты, перенесённые из программы производителя |
| `watercooler.py` | СЖО по Bluetooth LE: XMG Oasis Mk1 / Mk2 и аналоги, ступени, контроль циркуляции |
| `monitor.py` | температуры, загрузка, частоты, вентиляторы, мощность, диски, батарея |
| `automation.py` | режим по источнику питания, оповещения о перегреве, история (1 мин … 24 ч) |
| `backup.py` | экспорт / импорт настроек |
| `updates.py` | проверка обновлений и загрузка с проверкой суммы из релизов GitHub |
| `report.py`, `report_oem.py` | диагностический отчёт (zip) для сообщений об ошибках и новых ноутбуков |
| `agentcore.py` | тексты уведомлений, общие для агента Linux и трея Windows |

## Windows — `uwccd/win/`

| Файл | Что |
|---|---|
| `winservice.py` | хост службы Windows (перезапуск при сбое задаёт установщик) |
| `acpidrv.py` | доступ к EC через драйвер производителя `UWACPIDriver.sys` |
| `wmiec.py` | доступ к EC через встроенный WMI Windows (`AcpiTest_MULong`), открытая реализация, бета |
| `wmievents.py` | горячие клавиши из WMI `AcpiTest_EventULong` |
| `hid.py` | доступ к клавиатуре по HID (SetupAPI + hid.dll) |
| `sysinfo.py`, `pdhpower.py` | данные монитора в Windows, мощность CPU из счётчиков Energy Meter |
| `winplat.py`, `winapi.py` | мелкие помощники Windows (DMI, процессы, WMI), слой ctypes |
| `tray.py` | `ControlCenter.exe`: значок в трее, OSD, уведомления, обновления, перезапуск службы |
| `fxinput.py` | часть эффектов BetterRGB в трее: нажатия клавиш, картинка экрана, уровни звука |

## С чего начать

- **Новый ноутбук** — запустите на нём `uwccctl report`; номера проектов и возможности — в `hw.py`, регистры — в
  `regs.py`, режимы — в `fan_std.py`. Отчёт покажет, чем оригинальная программа этого ноутбука отличается.
- **Новая настройка / переключатель** — `settings.py` (служба), `api.py` (ключ настройки), `web/app.js` + `index.html`
  (интерфейс), `web/i18n.js` (русский текст), тест в `tests/test_mock.py`.
- **Интерфейс без ноутбука** — `python3 -m uwccd --mock --token test`, затем откройте
  `http://127.0.0.1:47321/#token=test`.
