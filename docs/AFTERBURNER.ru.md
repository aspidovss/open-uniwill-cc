# MSI Afterburner (экспериментально)

[English](AFTERBURNER.md) · **Русский**

С 1.7.1 каждый режим ноутбука может включать профиль **MSI Afterburner** (Windows). Разгон или андервольт видеокарты
остаётся в Afterburner: вы настраиваете его там, как обычно, и сохраняете в слоты профилей **1–5**. Эта программа
только говорит Afterburner, какой слот применить при смене режима — например, андервольт в Офисном и разгон в Турбо.

Это работает одинаково на ноутбуках Uniwill, Control Center 3.0 / Clevo и Leishen / Thunderobot: номера режимов те же,
что и в правилах автоматизации.

## Как пользоваться

1. В MSI Afterburner задайте частоты / кривую и сохраните их кнопкой *Save* в слот профиля 1–5.
2. Откройте «Выбор режима» → карточка **MSI Afterburner**: выберите профиль для каждого режима. На ноутбуках Uniwill,
   у режимов которых есть пресеты (Офисный 1 / 2, Игровой 1 / 2, Турбо 1 / 2, Пользовательский 1–5), у каждого пресета
   своя строка: Турбо 1 может включать профиль 3, а Турбо 2 — профиль 4. «Не менять» (по умолчанию) оставляет
   Afterburner как есть. Строка, которая работает сейчас, отмечена точкой.
3. Смените режим — в окне, в трее, клавишей режима Fn, правилом или переходом на батарею: применится профиль нового
   режима.

«Применить сейчас» (1–5) на карточке и меню в трее *MSI Afterburner → Профиль N* применяют слот вручную.

## По умолчанию (заводские настройки)

У командной строки Afterburner нет команды «сбросить», поэтому заводские частоты тоже хранятся в слоте: в Afterburner
нажмите **Reset**, затем **Save** в слот (например 1) и выберите этот слот как **«Стандартный профиль (заводские
настройки)»** на карточке. Тогда:

- кнопка **«По умолчанию»** (и пункт «По умолчанию» в трее) применяет его;
- **«По умолчанию»** в списке режима или пресета следует за этим слотом — поменяйте стандартный слот один раз, и все
  режимы с «По умолчанию» последуют за ним;
- **«Восстановить настройки по умолчанию»** внизу «Выбора режима» заодно сбрасывает выбор Afterburner у всех режимов и
  пресетов (обратно в «не менять»); сам стандартный слот остаётся.

## Когда применяется профиль

- меняется режим или его пресет, чем бы он ни был изменён (окно, трей, правила автоматизации, клавиша режима Fn,
  сеть / батарея);
- запускается служба (после перезагрузки Windows — профиль текущего режима);
- Afterburner запускается позже службы (иначе победил бы его собственный стартовый профиль; наш применяется через
  несколько секунд после него).

Программа не знает, какой профиль Afterburner использует сейчас: она показывает последний, который применила сама.
Профиль, выбранный в самом Afterburner, остаётся до следующей смены режима.

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| «Переключать профили Afterburner вместе с режимом» | вкл. | выкл.: в Afterburner ничего не отправляется |
| «Стандартный профиль (заводские настройки)» | не задан | слот, сохранённый после Reset в Afterburner |
| профиль каждого режима / пресета | «не менять» | «По умолчанию» или слот 1–5 |
| «Запускать Afterburner, если он не запущен» | вкл. | команда запускает закрытый Afterburner и применяет слот; выкл.: слот применяется, когда Afterburner запущен |

## Как это устроено

У MSI Afterburner есть документированная командная строка: `MSIAfterburner.exe -Profile1` … `-Profile5`. Запущенный
Afterburner принимает команду и применяет слот; закрытый — запускается и применяет его. Ничего из Afterburner не
используется и не поставляется; он находится по записи удаления в реестре или в `Program Files (x86)\MSI Afterburner`.

Afterburner работает с правами администратора, поэтому запуск команды из обычной программы каждый раз показывал бы
окно UAC. Поэтому её запускает служба (LocalSystem) в сеансе вошедшего пользователя с его полным токеном: окна нет, и
команда попадает в Afterburner этого сеанса. Пользователь должен быть администратором компьютера (Afterburner без этого
всё равно не работает). Если ещё никто не вошёл, слот применяется, как только пользователь войдёт.

**Экспериментально:** проверено с MSI Afterburner 4.6.6 (командная строка); запуск без окна при включённом UAC ещё
ждёт отчётов.

## Командная строка

```bash
uwccctl afterburner                      # найден ли, запущен ли, профиль каждого режима
uwccctl afterburner 3                    # применить профиль 3 сейчас
uwccctl afterburner mode turbo 3         # Турбо -> профиль 3 (Clevo / Leishen: их названия режимов)
uwccctl afterburner mode turbo.2 4       # Турбо, пресет 2 -> профиль 4 (важнее профиля самого режима)
uwccctl afterburner mode office keep     # Офисный: не менять
uwccctl afterburner default 1            # в слоте 1 заводские настройки
uwccctl afterburner default              # применить его сейчас
uwccctl afterburner mode office default  # Офисный -> стандартный слот
uwccctl afterburner off                  # не переключать профили вместе с режимом
uwccctl afterburner launch off           # не запускать закрытый Afterburner
```
