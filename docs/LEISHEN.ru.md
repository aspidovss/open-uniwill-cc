# Leishen / Thunderobot (экспериментально)

[English](LEISHEN.md) · **Русский**

Некоторые ноутбуки Thunderobot (например, **R16**, плата NLY, BIOS TP162) собраны Quanta и поставляются с
**Leishen ControlCenter 3.x**. У них нет ни интерфейса встроенного контроллера Uniwill, с которым работает остальная
программа, ни интерфейса Clevo DCHU (`CLV0001`), поэтому обычные страницы на них не работают. С их прошивкой работает
отдельный модуль `uwccd/leishen`. Он **экспериментальный**: написан по ACPI-таблицам прошивки и по тому, как с ними
работает Leishen ControlCenter 3.0.0.18 (анализ для совместимости, без кода и файлов производителя), и ещё не
проверялся на таком ноутбуке.

**Проверено на Thunderobot R16 (1.6.11_Leishen_dev):** датчики, режимы питания, своя скорость вентиляторов, подсветка
клавиатуры, клавиша Windows, тачпад и клавиша режима работают.

## Как это устроено

У прошивки один WMI-блок данных на 32 байта, GUID `644C5791-B7B0-4123-A90B-E93876E0DAAD` (WMI-класс `RW_GMWMI` в
`root\WMI`, устройство `GWMI`). Запись блока выполняет команду в ACPI-методе `WSAA`, чтение (`WQAA`) возвращает ответ в
той же раскладке:

| Байты | Поле | |
|---|---|---|
| 0–1 | `a0` | `0xFA00` чтение, `0xFB00` запись; ответ `0x1000` — команда неизвестна |
| 2–3 | `a1` | функция |
| 4–23 | `a2`…`a6` | значения (по 32 бита) |

| Функция | Чтение (`0xFA00`) | Запись (`0xFB00`) |
|---|---|---|
| `0x200` | `a2` CPU °C, `a3` GPU °C, `a4` / `a5` обороты вентиляторов 1 / 2, `a6` уровень подсветки | `a2` 0: `a6` 1 = клавиша Windows заблокирована |
| `0x201` | `a2` `0x34` RGB-клавиатура, `0x35` одноцветная | — |
| `0x202` | флаги оборудования | `a2` 0 / 1 тачпад выкл. / вкл. |
| `0x205` | `a2` заводская таблица вентиляторов (4 = NLY) | `a2` / `a3` / `a4` скорость вентиляторов 1 / 2 / 3, %; `0xFF` — этот вентилятор автоматически |
| `0x206` | `a2` бит «программа управления запущена» | тот же бит (прошивка записывает `a2`, затем `a3`) |
| `0x207` | `a2` GPU °C, `a3` обороты вентилятора 3 | — |
| `0x300` | `a2` режим питания: 0 Высокая производительность, 1 Игровой, 2 Офисный | то же; прошивка заодно задаёт пределы мощности NVIDIA |
| `0x100` | — | подсветка клавиатуры: `a2` зона, `a3` = эффект << 28, уровень << 24, RRGGBB |

Каждое чтение `0x200` заодно ставит в контроллере бит «программа управления запущена» — Leishen ControlCenter тоже
читает эту функцию каждые несколько секунд. Поэтому *автоматический* режим вентиляторов — это `0x206` = 0 **и**
`0x205` = `0xFF` для каждого вентилятора: один бит вернётся при следующем чтении, и останутся прежние скорости.

- **Windows:** встроенный в Windows WMI-драйвер, дополнительный драйвер не нужен.
- **Linux:** `acpi_call` к методам `WSAA` / `WQAA` устройства (`sudo modprobe acpi_call`).

## Что делает модуль

| | |
|---|---|
| **Монитор** | температура CPU и GPU и обороты 2 или 3 вентиляторов из прошивки — также на странице «Монитор» и в истории |
| **Режим питания** | Высокая производительность / Игровой / Офисный, текущий режим читается из прошивки. Офисный заодно ограничивает видеокарту (пределы мощности NVIDIA в прошивке) и останавливает системный вентилятор. От батареи режим — Офисный, как в Leishen ControlCenter; режим, выбранный от сети, возвращается с зарядкой («Офисный от батареи», по умолчанию вкл.) |
| **Вентиляторы** | *Автоматический* (контроллер), *Постоянная скорость* или *Кривая* для вентиляторов процессора и видеокарты, которую служба применяет каждые 2 с, как Leishen ControlCenter (заводская кривая NLY: 30 % до 70 °C, дальше 50 / 60 / 70 / 100 %). Leishen ControlCenter не опускается ниже 30 % (≈1450 об/мин, системный ≈1800); здесь работает 20 % (≈1000 об/мин, системный ≈1250), ниже — только после вопроса. Системный вентилятор остаётся автоматическим, если для него не задана своя скорость (в Офисном режиме постоянная скорость заставляла его скакать между 1000 и 2000 об/мин). Когда служба останавливается, вентиляторы возвращаются в автоматический режим |
| **Клавиатура** | блокировка клавиши Windows, тачпад вкл. / выкл.; на RGB-клавиатурах — зона, эффект (статичный, дыхание, смена цветов, ambilight), уровень и цвет. На одноцветной клавиатуре команда подсветки не отправляется (прошивка ждёт RGB-контроллер); уровень показывается и меняется клавишами Fn |
| **Клавиша режима** | (Windows, по умолчанию выкл.) клавиша режима Fn переключает Офисный → Игровой → Высокая производительность, как это делает Leishen ControlCenter. Включайте, только если Leishen ControlCenter закрыт |

Пока не включено **«Разрешить команды»** (страница «Leishen (экспериментально)» или `uwccctl leishen writes on`), ничего
не отправляется. Прошивка не сообщает состояние клавиши Windows, тачпада и цвета подсветки: страница показывает
значения, заданные на ней последними. Сохранённые настройки (режим, постоянная скорость вентиляторов, клавиша Windows)
отправляются снова при запуске службы (можно выключить).

Не сделано: переключение режима дисплея (`0x203`, нужна перезагрузка), частоты обновления (`0x204`), события камеры и
адаптера.

## Командная строка

```bash
uwccctl leishen                         # состояние
uwccctl leishen writes on               # разрешить команды
uwccctl leishen mode office             # performance | gaming | office
uwccctl leishen fan fixed 50 50         # CPU GPU [SYS|auto] %, ниже 20 % — с --low
uwccctl leishen fan curve 30:30 70:50 80:60 90:70 100:100
uwccctl leishen fan auto
uwccctl leishen winkey lock             # lock | free
uwccctl leishen touchpad off            # on | off
uwccctl leishen light all static 2 00A0FF   # RGB-клавиатуры: ЗОНА ЭФФЕКТ УРОВЕНЬ(0-2) RRGGBB
uwccctl leishen hotkey on               # Windows: клавиша режима
uwccctl leishen battery-office off      # от батареи оставлять выбранный режим
```

## Проверка

1. Закройте Leishen ControlCenter (в трее) — иначе команды будут отправлять обе программы.
2. Откройте «Leishen (экспериментально)»: температуры и обороты должны совпадать с Leishen ControlCenter.
3. Включите «Разрешить команды», попробуйте режим питания, затем вентиляторы («Постоянная скорость» 60 %, потом
   «Автоматический»).
4. Сделайте диагностический отчёт («Информация → Диагностический отчёт»): в нём есть необработанные ответы прошивки.
