About

Diagnostic report

A zip file with everything needed to add support for another laptop or to look into a problem: the EC registers the program uses, BIOS settings (UniWillVariable, SmartAPC), keyboard and light bar devices, NVIDIA limits, sensors and the service log. Nothing is changed on the laptop.

Included

Private details

Usually not needed. Tick them only if the developer asks.

Turn on, repeat the problem, then create the report: the log will contain every command sent to the hardware. Turn off afterwards.

Mode selection

Power and fan operating mode. The Fn + mode key cycles through them.

Mode profile

Fan Boost

Fans run at maximum speed

Performance boost

Works in any mode and stays on when you switch modes.

Super performance

Turbo fan mode with the factory Turbo fan curve and the maximum graphics power (cTGP + Dynamic Boost). The power limits of the current mode stay; its fan curve and graphics settings are not used while it is on.

RAM overclocking

The BIOS raises the memory frequency at the next start of the laptop. Unstable memory can keep the laptop from starting — then reset the BIOS settings to defaults.

Fan settings

Fan curves for every profile. Changes apply immediately if the profile is active.

Presets:
A preset only changes the editor; press Save to write it.

Drag the points: horizontally — the temperature at which a level starts, vertically — fan speed. Set the release temperature in the table.

Processor power for the profile

PL1 — sustained power, PL2 — short-term power (W). Values for AC and battery.

Liquid cooling

Cooling mode

The OEM software never uses 12 V; prefer 7–11 V for continuous operation.

Automatic mode: temperature tiers

Switching to a lower tier also waits for the temperature to drop 3 °C below the threshold. In the Controller mode the table is used when the EC publishes no targets; the settings below apply to both modes.

Coolant filling

After refilling, run the cycle to push air out of the loop: the pump is pulsed 8 times (about 70 seconds), then your settings are restored.

Options

While the cooler runs with normal coolant flow, the laptop's controller uses its own fan table for liquid cooling and the firmware raises the power level ("CoolingOC" of the original Control Center). Your fan curves are not used meanwhile; it switches off by itself when the cooler disconnects or the flow fails.

Firmware updates (DFU) are not performed by Control Center.
